Navbar Component

Fixed at the top. Transparent on load, solid when scrolled. Dark/light toggle built-in.

Your Name

"Nayeem" in bold accent color

Nav Links

Home · About · Skills · Projects · Contact

Dark Toggle

Sun/moon icon — switches theme

Scroll Effect

Blur + shadow when page scrolls down

File: components/Navbar.tsx

  ● ● ●

 1  'use client'

 2  import { useState, useEffect } from 'react'

 3  import { useTheme } from 'next-themes'

 4  import { FiSun, FiMoon, FiMenu, FiX } from 'react-icons/fi'

 5

 6  const links = ['About', 'Skills', 'Projects', 'Contact']

 7

 8  export default function Navbar() {

 9    const [scrolled, setScrolled] = useState(false)

10    const { theme, setTheme }     = useTheme()

11

12    useEffect(() => {

13      const onScroll = () => setScrolled(window.scrollY > 50)

14      window.addEventListener('scroll', onScroll)

15      return () => window.removeEventListener('scroll', onScroll)

16    }, [])

17

18    return (

19      <nav className={`fixed top-0 w-full z-50 transition-all

20        ${scrolled ? 'bg-slate-900/95 backdrop-blur shadow-lg' : 'bg-transparent'}`}>

21        <div className='max-w-6xl mx-auto px-6 py-4 flex items-center justify-between'>

22          <span className='text-accent font-bold text-xl'>Nayeem</span>

23          {/* Nav links */}

24          <ul className='hidden md:flex gap-8'>

25            {links.map(l => (

26              <li key={l}><a href={`#${l.toLowerCase()}`}

27                className='text-text-sub hover:text-accent transition-colors'>{l}</a></li>

28            ))}

29          </ul>

30          {/* Theme toggle */}

31          <button onClick={() => setTheme(theme==='dark' ? 'light' : 'dark')}

32            className='p-2 rounded-lg bg-bg-card'>

33            {theme === 'dark' ? <FiSun size={18}/> : <FiMoon size={18}/>}

34          </button>

35        </div>

36      </nav>

37    )

38  }

Framer Motion Animations

Use these 4 patterns throughout. Never mix more than 2 on a single component.

Pattern 1 — Fade Up   Most Used

Use on section headings, cards, and text. Elements fade in while sliding up.

Pattern 2 — Stagger   Card Grids

Multiple cards appear one by one with 0.1s delay. Looks very polished.

Pattern 3 — Hover Lift   Cards

Card lifts -8px on hover with subtle glow. Use on project and skill cards.

Pattern 4 — Slide In   About Section

Photo from left, text from right. Creates great visual tension.

  ● ● ●

 1  // Pattern 1 — Fade Up

 2  <motion.div

 3    initial={{ opacity: 0, y: 40 }}

 4    whileInView={{ opacity: 1, y: 0 }}

 5    transition={{ duration: 0.5 }}

 6    viewport={{ once: true }}>

 7    {/* content */}

 8  </motion.div>

 9

10  // Pattern 2 — Stagger (parent)

11  const container = { hidden: {}, show: { transition: { staggerChildren: 0.1 } } }

12  const item = { hidden: { opacity: 0, y: 20 }, show: { opacity: 1, y: 0 } }

13  <motion.div variants={container} initial="hidden" whileInView="show">

14    {projects.map(p => <motion.div key={p.id} variants={item}>{/* card */}</motion.div>)}

15  </motion.div>

16

17  // Pattern 3 — Hover Lift

18  <motion.div

19    whileHover={{ y: -8, scale: 1.02 }}

20    transition={{ duration: 0.2 }}>

21    {/* card content */}

22  </motion.div>

23

24  // Pattern 4 — Slide In (About)

25  <motion.div initial={{x:-60,opacity:0}} whileInView={{x:0,opacity:1}}>photo</motion.div>

26  <motion.div initial={{x:60,opacity:0}}  whileInView={{x:0,opacity:1}}>text</motion.div>

  PART 12

Deploy on Vercel

From code to live URL in under 5 minutes. Completely free.

01

Go to github.com → Create new repository called "portfolio" (public)

02

Run:  git init → git add . → git commit -m "init" → git push

03

Go to vercel.com → Sign in with your GitHub account

04

Click "New Project" → Import your portfolio repository

05

Leave ALL settings as default → Click Deploy

06

Wait 1–2 minutes → Your site is live at username.vercel.app

07

(Optional) Add a custom domain in Settings → Domains (e.g. nayeemdev.com)

  💡  After deployment, add your Vercel URL to:  CV  ·  LinkedIn profile  ·  GitHub bio  ·  email signature
